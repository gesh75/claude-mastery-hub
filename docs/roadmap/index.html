Architecture

Content & engines

index.html — sections plus the QUIZ, EXAM, and LAB data-driven engines.

Model fact registry

MODEL_FACTS, MODEL_SOURCES, BENCHMARK_EVIDENCE — one place for volatile facts with a verification date.

Persistence

localStorage keys claude_hub_quiz/exam/mastery/lab_v1, validated and version-2 migrated, with deterministic cross-tab merge. claude_hub_nav_v1 is a separate single-flag preference with its own guarded read/write, outside the state layer.

Quality gate

.github/workflows/ci.yml plus scripts/check-*.mjs — structural parsing, not text matching.

Product invariants

  • One file, zero dependencies — no build step, no network at load.
  • Fully offline — external documentation links allowed; external subresources are not.
  • Progress is the user's — localStorage only, no backend, no telemetry.
  • Contained layout — no document-level horizontal overflow from 320 px up.
  • Keyboard accessible — a closed mobile menu exposes no focusable controls.
  • Facts verified, not remembered — claims carry a verification date.

Decision history

enforce_admins: true on main

The gate exists so nothing reaches main unverified. An admin bypass would cover 100% of traffic here, since the maintainer is the only contributor. Cost: every change, including a one-line doc fix, is now a PR.

Structural parsing over regex for security-critical checks

Three formatting-sensitive bypasses were found: uses : with a space, var helper, top = 1, and single-quoted style='…'. Workflows are now parsed with yaml and inline scripts with acorn.

yaml pinned to 2.9.0, not 2.6.1

2.6.1 carries a moderate stack-overflow advisory. --audit-level=high would have accepted it, but this parser reads workflow files from fork PRs — a vulnerable parser inside the security gate is the wrong trade.

ARC-AGI-3 shows both the exact and rounded score

ARC Prize publishes 30.16% in its verified table and 30.2% in the headline. An earlier pass read only the headline and added a test forbidding the exact value, locking in the error. Assertions now check the relationship between the two.
